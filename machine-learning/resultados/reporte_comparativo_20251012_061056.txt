📋 MÉTRICAS EXPLICADAS:
• R² (0-1): Porcentaje de varianza explicada. >0.8=Excelente, >0.6=Bueno
• MAE: Error absoluto promedio (unidades originales)
• RMSE: Error cuadrático (penaliza errores grandes)
• MAPE: Error porcentual promedio
• Tiempo Entrenamiento: Tiempo para ajustar el modelo
• Tiempo Predicción: Tiempo para generar 24h de predicciones
• Score Eficiencia: R² dividido por tiempo total (mayor = mejor)
• ⚡<1s=Muy Rápido, 🟢1-5s=Rápido, 🟡5-15s=Moderado, 🟠>15s=Lento
